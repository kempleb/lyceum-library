# CANON.md — the living roadmap

This file is the canon boundary, the wave plan, and the translation-status table
for the Classical Philosophy Reader. It is maintained as work proceeds —
canon-boundary judgment calls get logged here as they're made, not just planned.
Source of record for the reasoning behind these calls:
`ancient-philosophy-reader-plan.md` (esp. §1.4, §2, §5).

## 1. Canon boundary

**Scope statement:** Ancient philosophy, Thales to Boethius, Greek and Latin,
original texts complete with English wherever a free translation exists.

The architecture deliberately keeps nothing Bekker/Stephanus/ancient-specific, so
a medieval wing (Aquinas, etc.) would be a data addition, not a fork — but it is
**out of scope** for this project as currently chartered.
